# Spotify Lyrics Crosshair (Fabric, Minecraft 1.21.11)

Songtexte unter dem Fadenkreuz (aus der Windows-Mediensteuerung, kein Premium noetig) plus gelegentliche
Effekte (Sternschnuppen, Windboeen).

Befehle: /lyrics on|off|toggle · status · reload
/lyrics scale · y · width · lines <davor> <danach> · offset <ms> · speed · shadow <true|false>
/lyrics color highlight <RRGGBB> · color normal <RRGGBB>
/lyrics fx on|off · fx rate <1-10>
